Política de Privacidade

Caderninho de Receitas · Última atualização: 24 de agosto de 2026 · English version

Resumo: os seus dados ficam no seu computador. O Caderninho de Receitas não tem contas, não tem servidores próprios e não recolhe, transmite nem vende qualquer informação sua.

1. Quem somos

O Caderninho de Receitas é uma aplicação de gestão de receitas, inventário e custos de cozinha, publicada de forma independente. Para qualquer questão sobre privacidade, contacte: caderninho-de-receitas@outlook.com.

2. Dados guardados localmente

Toda a informação que introduz na aplicação — receitas, ingredientes, inventário, fornecedores, registos financeiros e preferências — é guardada exclusivamente numa base de dados local, no seu dispositivo. Nós não temos acesso a estes dados, nem eles passam por servidores nossos em nenhum momento.

As cópias de segurança são ficheiros criados no seu dispositivo, na pasta que escolher. A gestão, partilha e eliminação desses ficheiros está inteiramente sob o seu controlo.

3. Serviços de terceiros (opcionais)

Duas funcionalidades opcionais comunicam com serviços externos, apenas quando as utiliza:

Leitura de faturas (OCR). Se optar por digitalizar uma fatura, a imagem é enviada diretamente do seu dispositivo para a API Google Gemini, usando uma chave API sua. As faturas podem conter dados pessoais (nomes, números fiscais, moradas); o tratamento dessa imagem pela Google rege-se pelos termos de privacidade da Google. Não usamos esta funcionalidade em seu nome nem vemos o conteúdo enviado.

Pesquisa de produtos por código de barras. Ao pesquisar um produto, o código de barras é consultado na base de dados pública Open Food Facts. Apenas o código de barras é enviado; como em qualquer pedido na internet, o seu endereço IP é visível para esse serviço.

4. O que não fazemos

A aplicação não contém análises de utilização (analytics), publicidade, rastreadores nem telemetria. Não criamos perfis, não partilhamos dados com terceiros e não enviamos comunicações não solicitadas.

5. Os seus direitos e controlo

Como os dados vivem apenas no seu dispositivo, o acesso, a exportação (através das cópias de segurança) e a eliminação estão sempre nas suas mãos. Para apagar todos os dados, basta remover os dados da aplicação ou desinstalá-la, e eliminar as cópias de segurança que tenha criado.

6. Alterações a esta política

Se futuras versões da aplicação alterarem a forma como os dados são tratados (por exemplo, sincronização na nuvem), esta política será atualizada antes dessa funcionalidade chegar até si, com a data de revisão indicada no topo.
